# 🍅 番茄钟

基于 Electron 的桌面番茄钟，无边框设计，支持系统托盘常驻。

## 功能

- **三种模式** — 25 分钟专注 / 5 分钟小休 / 15 分钟长休，每 4 轮自动切长休
- **环形倒计时** — 可视化进度环，实时显示剩余时间
- **桌面通知** — 计时结束弹出系统通知 + 提示音
- **系统托盘** — 关闭窗口后托盘常驻，不中断计时
- **暗色主题** — 一键切换浅色 / 暗色
- **键盘快捷键** — `空格` 开始暂停，`R` 重置，`S` 跳过，`1/2/3` 切换模式

## 开发

```bash
# 安装依赖
npm install

# 启动
npm start
```

## 技术栈

- Electron
- HTML5 Canvas（环形进度）
- Web Audio API（提示音）
- Web Notification API（桌面通知）
